# Source programs and configurations

These files mirror the Python sources and fixed configurations in the [version 0.22 research archive](https://github.com/vincent-zhang0116/stable-ou-identification/releases/download/v0.22/Stable_OU_Research_Materials_v0.22.zip). Their relative paths and bytes are preserved. `SOURCE_SHA256.json` records the archived hashes.

For reproduction, download and extract the complete research archive. It also contains recorded random streams, simulation results, selected arrays, display inputs and the integrity manifest required by the entry point. Running this browsable source subset alone is insufficient.
